# Vector Soar — macOS Help

Aerial arcade combat — altitude wins

## How to play

Pilot a broad-winged eagle through waves of aerial enemies. Steer, flap to climb, fire forward and dive to gain speed.

## Keyboard and mouse controls

| Control | Action |
|---|---|
| Left / Right or A / D | Steer. |
| Space | Flap to climb. |
| F | Fire forward. |
| Shift | Dive. |
| Return | Start or restart. |
| P | Pause or resume. |

## Scores, saves and settings

The local high-score record is retained on your Mac. This game does not currently advertise a Save Game / Load Game feature; do not assume a running battle will resume after quitting.

## Application menus

The native **Game** menu offers How to Play, Controls & Shortcuts, and Scores & Saving. The **Help** menu opens these offline instructions. Standard macOS App, Edit, Window, and Quit commands remain provided by the operating system. In-game gameplay buttons and shortcuts are unchanged.
